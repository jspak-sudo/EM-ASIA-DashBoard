• 기본 DCA 대비 +1.0% 효율 향상
• 핵심: 드로다운 단계가 깊어질수록 더 많이 사라 (단계별 추가매수가 가장 효율)
• -3% 일별 추가매수는 너무 잦아 자금 분산이 단계별보다 덜 효과적
⚠️ 주의:
• "공격적 -20%/-30% 추가매수" 전략은 여유자금이 있어야 가능 — 폭락 시점에 큰 돈 동원 능력 필요
• 큰 하락(-30%)이 안 오면 추가매수 안 함 → 다른 곳에 자금 묶임 (기회비용)
• 평균투자단가가 낮아져 보이지만 자금이 폭락 시점에 묶이는 리스크 인지 필요

📌 종합 권장 (실전 전략)

📉 회피파라면 (Q1)

  1. -3% 매도 후 즉시 재진입 금지 — 추가하락 확률 90%
  2. "저점 +5~10% 반등 확인" 또는 "20일 후 AND 가격>MA20" 후 재진입
  3. 단순 N일 후보다 신호 기반이 휩쏘를 줄임
  4. 가장 안전: 가격 > 200일 이평선 회복 후 재진입 (보수적)

💰 추가매수파라면 (Q2)

  1. 매월 정기 적립을 기본으로 유지 (시간 분산)
  2. 일일 -3% 같은 잦은 신호보다 드로다운 단계 기반이 효율적
    예: -10% 진입 시 2배, -15% 진입 시 3배, -20% 진입 시 5배
  3. 현금 비축: 항상 일정 비율 (10~20%) 현금 유지 → 폭락 시 동원
  4. "한번에 다 쏘기"보다 단계별로 사는 게 평균단가 ↓

🤝 결합 전략 (회피+추가매수 하이브리드)

  1. 핵심 포지션 70%는 절대 매도 안 함 (DCA + 드로다운 추가매수)
  2. 나머지 30%만 "회피 신호" 사용 (전체 매도 X)
  3. 회피분은 -3% 시 매도 → 저점 +10% 반등 시 재진입
  4. 장기 수익률과 변동성 양쪽 모두 균형
